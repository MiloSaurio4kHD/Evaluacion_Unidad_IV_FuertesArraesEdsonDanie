# 03_DocumentoEntregable

Documento que se sube al LMS (SGA). Contiene la carátula con los datos de
identificación, la URL del repositorio en una sola línea y las capturas del
cuestionario del SGA.

| Archivo | Descripción |
|---|---|
| `Entregable_EV4_FuertesDaniel.tex` | Archivo fuente de la carátula. |
| `Entregable_EV4_FuertesDaniel.pdf` | PDF que se entrega. |
| `evidencias/` | Capturas del SGA en PNG (carátula) y los PDF completos (anexos). |

## Compilación

Una sola pasada, sin bibliografía:

```bash
pdflatex Entregable_EV4_FuertesDaniel
```
